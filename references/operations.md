# 운영 규칙 상세

`SKILL.md` 본문에는 요약만 있고, 자세한 조건과 표는 여기에 둔다.

## 자동 발동 조건 (하나라도 해당하면, 중 단계, 한 턴에 최대 1번)

- 일반 검색 결과가 빈약하거나 뻔하거나 한쪽 출처로 쏠림 (1회만 해도)
- 대상이 희귀하거나 모호하거나 이름을 모름, 또는 이름 없이 속성만 앎
- "~가 언급된/쓰인 곳을 전부" 찾아야 하는 요청 (표기가 다를 수 있으므로)
- 지워지거나 이름이 바뀌거나 옮겨진 것을 추적해야 함
- 놓치면 손해가 큼 (돈, 보안, 법적 문제, 되돌리기 어려운 작업 직전, 의사결정의 근거)
- 중요한 정보 (사용자가 중요하다고 했거나 결론의 핵심 근거)
- "없다/못 찾았다"로 결론 내리기 직전, 또는 후보가 1개뿐인데 확정하려 할 때
- 분석 중 출처를 모르는 이상치를 발견
- 사용자가 "이미 찾아봤는데 안 나와", "놓친 거 없나"라고 함
- 오래됐을 가능성이 있는 정보

**쓰지 않는 경우:** 명백히 사소한 단순 조회(파일 한 줄 읽기, HEAD 해시, 이미 아는 명령 하나 등). 
작은 코퍼스(수백 파일)에서 직접 grep 몇 번으로 끝나는 결정적 작업(git 이력 추적 등)은 스킬 없이도 되지만,
**표기가 다를 수 있는 언급 전부 찾기**와 **이름 없이 속성만 아는 찾기**는 규모와 무관하게 쓴다.

자동으로 켤 때는 한 줄로 알린다. 예: "결과가 빈약해 보강 탐색합니다."

## 끄기 스위치

사용자가 "자동 보강 끄기", "숨은 거 찾기 그만", "이번엔 그냥 검색만 해줘" 등으로 말하면
**자동 발동만** 그 대화가 끝날 때까지 멈춘다. 명시 요청은 꺼져 있어도 실행한다.
"자동 보강 켜기" 등으로 복귀한다. 정확한 문구가 아니라 의도로 판단한다.

## 멈출 때

- **하나만 찾으면 되는 요청:** 첫 기법에서 나온 후보가 감정을 통과하면 늘리지 않고 끝낸다.
- **전부 찾아야 하는 요청(목록이 목표):** 새 각도를 시도했는데 **새 후보가 0개**인 **라운드**가
  **연속 2번** 나오면 끝낸다.
  - **라운드 = 서로 다른 축에서 만든 기법 한 세트를 실행하는 것.** 같은 기법의 쿼리 몇 개는 한 라운드다.
  - **전수 집계나 전수 스캔(`tally.py`, `normscan.py` 등)으로 대상 전체가 이미 확인됐으면** 라운드를 채우려고
    일부러 질의를 더 만들지 않고 감정으로 넘어간다.
- 한 턴에 쓰는 축은 중 단계에서 3~4개까지. 강 승격 신호가 있을 때만 넘는다.

## 강으로 승격 (일부만)

| 신호 | 추가 |
|---|---|
| 후보가 없어 "없다"고 결론 내려야 함 | 시도한 축과 기법을 점검하고 빠진 것을 보충. 못 찾았으면 "미확정"으로 보고 |
| 대상이 방대함 | 축별 병렬 서브에이전트 |
| 후보가 많음 | 감정 전체 적용 |
| "철저히", "끝까지" | 기록을 파일로 남기고 반복 |

## 사용자가 형식이나 범위를 정했을 때

- **출력 형식을 지정하면 그 형식이 우선이다.** 예: "`- 경로` 한 줄씩". 이때 보고 형식(시도 기록, 못 본 곳)은
  생략하거나 답 끝에 한두 줄로만 덧붙인다. 지정한 형식을 깨지 않는다.
- **범위를 제한하면 그 안에서만 쓴다.** 예: "이 경로 밖은 보지 마", "인터넷은 쓰지 마". 이 경우 `길`(다른 검색엔진,
  공개 API)과 `시간`(웹 아카이브)은 범위 안에서 가능한 기법만 쓰고, 못 쓴 축은 한계에 한 줄로 적는다.

## 보고 형식 상세

```
찾은 것: (후보마다 [확인 수준] / [근거 수준] / [직접 | 간접])
고른 축과 만든 기법:
시도 기록: (쿼리/범위/결과 수)
못 본 곳 / 한계:
```

- **확인 수준:** 내가 얼마나 확인했나 → 확인됨 / 부분 / 미확인
- **근거 수준:** 정보 자체의 출처가 얼마나 믿을 만한가 → 공식 확인 / 독립 출처 일치 / 단일 출처 / 소문
- **직접 / 간접:** 대상이 직접 적혀 있나, 인코딩·난독화를 풀었나, 리다이렉트·단축 링크 체인을 거쳐야 닿나.
  체인은 "출발 문서 → 매핑 파일 → 최종 목적지"를 모두 적는다. 사용자가 형식을 지정했으면 간접 후보는
  본 목록에 넣을지 말지를 판단해 한 줄 이유와 함께 적는다.
- **내용을 직접 열어 확인할 수 없는 후보**(예: 단축 링크의 목적지, 접근이 막힌 글)는 정답 목록에 섞지 않고
  "미확인 후보"로 따로 적는다.
