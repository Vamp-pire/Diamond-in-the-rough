# 8개 축: 질문, 예시 기법, 함정

각 축은 대상에게 던지는 질문이다. **예시 기법은 시작점**이며 목록 밖 기법을 만들어 쓰는 것이 이 스킬의 핵심이다.
기법을 만들 때는 "이 대상이 이 축에서 어떻게 달라 보일 수 있나?"를 구체적으로 상상해서 한 문장으로 적고 시도한다.

---

## 1. 표현 — 다르게 표현됐을 수 있나?

**다른 말**
- 한글↔영문 음역 (PartnerHub ↔ 파트너허브), 영어 이름의 한글/일문 표기
- 별칭, 약어와 풀네임, 코드명, 옛 이름, 번역 제목, 오타
- 사용자가 겪는 문제를 **사용자의 말투**로 적은 문장

**다른 꼴**
- 인코딩: URL 인코딩(`%2F`, 점이 `%2E`인 것, `%252F` 이중 인코딩), HTML 엔티티(`&#46;`), base64, 16진수·`\u` 이스케이프
- 난독화: `[.]`, `(dot)`, `hxxp`, 쪼갠 표기, 전각 문자, 보이지 않는 공백, 줄바꿈이나 `<wbr>`로 분할
- 매체: 이미지·캡처·스캔 PDF·영상·음성 속 글자(OCR, 자막, alt 텍스트, 메타데이터)

**문서마다 다른 식별자:** 한 곳엔 활동명·별명·ID, 다른 곳엔 본명·정식 이름만 있는 경우가 흔하다.
먼저 매핑 문서에서 한 단계 풀고(활동명 → 본명), 풀린 이름으로 본 문서를 역조회한다.

**짧은 ID·매핑 체인:** 문서에는 `go.example/ap1`처럼 짧은 ID만 있고 최종 주소는 매핑 파일(csv/json)에 있는 경우가 많다.
`normscan.py --follow-maps`가 최종 주소에서 거꾸로 짧은 ID를 쓰는 문서를 '간접(체인)'으로 찾아 준다.

**도구:** `scripts/variants.py`(변형 목록, `--regex`로 정규식 한 줄), `scripts/normscan.py`(폴더 전체를 정규화해 스캔,
음역·브랜드명은 `--term`을 따로 준다). 목록 밖 모양(전각, 보이지 않는 공백, 줄바꿈 분할 등)은 `normscan.py`가 잡는다.
**함정:** 같은 쿼리를 어순만 바꿔 반복하는 것. OCR은 숫자·URL을 원본과 대조한다.
**끝까지 따라가기:** 단축 링크나 리다이렉트 매핑 파일이 있으면 최종 목적지로 판단한다.

---

## 2. 위치 — 어디에 있을 수 있나?

- 같은 문서 안: 본문 밖의 href·속성, 메타데이터, 제목, 댓글, 각주, 푸터, 파일명, 설정 파일, 첨부
- 다른 문서·폴더·저장소
- 다른 시스템·플랫폼: 이슈 트래커, 위키, 별도 게시판, 내부 검색, 다른 서비스

**함정:** 본문 검색 결과만 보고 끝내는 것. 후보 장소를 먼저 넓게 적고 하나씩 뒤진다.
**연결과의 차이:** 장소를 넓혀 직접 뒤지면 위치, 아는 것에서 관계를 타고 건너가면 연결.

---

## 3. 연결 — 아는 것에서 이어 갈 수 있나?

- 웹: 그 대상을 링크하는 곳(백링크), "대안", "alternatives to X", 큐레이션 목록, 전문가가 링크하는 곳
- 유입: referrer, 공유·인용 위치
- 코드: 호출자, import하는 곳, 의존성 목록, 이슈·PR 언급
- 게시물: 인용·공유 링크, 같은 작성자의 다른 글
- 복제본: 퍼온 글이면 원문 표기와 최초 게시 시점을 따라 올라가 **원출처** 찾기
- 사람·작품: 출연진 → 출연작, 작가 → 작품, 이름 → 필모그래피(크레딧 DB)

**함정:** 연결을 한 단계에서 멈추는 것. 최종 목적지나 원출처까지 간다.

---

## 4. 시간 — 언제 있었고 언제 있을까?

- 과거: 웹 아카이브, 검색엔진 캐시, git 이력(`git log -G`, `git log --all`), 릴리스 노트·체인지로그, 옛 버전.
  삭제된 함수·클래스는 `scripts/gittrace.py --find 단어`로 후보를 찾고 `--symbol`로 삭제 → 이동 → 이름 변경 체인과 HEAD의
  현재 위치를 본다. 이름이 비슷해도 내용이 다른 기능(예: 구분자만 다른 옛 스크립트)은 유사도로 가려낸다
- 변경: 이름이 바뀐 이력, 이동·삭제된 시점, 두 버전의 비교
- 미래(공개 전): 선행 흔적. 버전 차이(`scripts/diffsets.py`), 등록·심의·목록 변경, 예고된 일정, 개발자 발언, 번역·현지화 문자열. 이후 공식 발표와 대조해 적중률을 기록한다
- 휘발: 사라지기 전에 즉시 보존하거나 보존본을 찾는다

**함정:** 지금 상태만 보는 것. 날짜를 좁혀서 찾는다.

---

## 5. 분포 — 모아 놓으면 무엇이 튀나?

- **집계:** `scripts/tally.py`로 항목별 빈도. 상위가 아니라 **꼬리와 예상 밖 이름**을 본다. 봇·내부 트래픽은 먼저 제거.
  combined 로그는 `--field 2`로 referrer만 본다(`-`는 직접 방문으로 따로 센다). 글 단위로 보려면 `--extract url`(쿼리에 글 ID가
  있으면 `urlq`), 스팸 도메인은 `--collapse-digits`와 `--ignore-regex`로 한 줄로 접는다. `--ignore`는 하위 도메인까지 제외하므로
  `naver.com` 대신 `search.naver.com`처럼 구체적으로 쓴다
- **감싼 주소 풀기:** 집계 전에 리다이렉터·공유 링크가 감싼 안쪽 주소를 꺼낸다(`google.com/url?q=URL`,
  `l.facebook.com/l.php?u=URL`, `url=`, `target=` 등). 안 풀면 안쪽 출처가 `google.com`, `facebook.com` 같은
  겉 도메인으로 뭉개져 사라진다. `tally.py --unwrap`. 도메인 단위 집계 뒤에는 `--extract host+path1`로 경로까지 본다
- **꼬리 끝까지 보기:** 고유 항목이 많으면 기본 출력(상위 20 + 눈여겨볼 항목 30)에 꼬리가 안 보인다.
  `--top`과 `--rare-limit`을 키우고, 스팸·봇 같은 흔한 패턴은 `--ignore`로 걷어낸 뒤 본다
- **비교:** `scripts/diffsets.py`로 두 버전에서 새로 생긴 항목만
- **함께 나오는 파일:** `scripts/cooccur.py <폴더> --term A --term B`로 두 용어가 모두 있는 파일(또는 같은 줄)을 모은다.
- **교집합:** 아는 속성마다 후보 집합을 만들고 교집합을 구한다(출연진 A의 작품 ∩ 출연진 B의 작품 ∩ 연도).
  `scripts/intersect.py <파일들> --section 출연작`. 교집합 후보가 여럿이면 남은 속성(연도, 줄거리)으로 거른다
- **제외:** 흔한 것을 걷어내고 남는 것을 본다
- **좁히기:** 먼저 **개수**부터 센다. 출력이 잘렸는지 확인. 부정 조건, 조건 교차, 기간·경로·종류로 나눠 구간별로 본다
- **넓히기:** 상위 개념으로 올리기, 동의어 확장, 조건 완화, 범위 확대

**전제:** 집계·비교할 기록이 있어야 한다. 없으면 연결·사람·길로 간다.
**함정:** 상위만 보는 것. 잡음을 안 걷어내고 해석하는 것. **도메인 단위 집계가 감싼 주소를 가리는 것.**

## 6. 성질 — 이름 없이 어떤 속성으로 가려낼 수 있나?

- 하는 일(의미)로 찾기: 키워드가 달라도 같은 일을 하는 코드·문서
- 패턴: 정규식, 구조(헤더 형식, 함수 모양, 필드 구성)
- 메타 속성: 크기, 날짜, 형식, 작성자, 수정 시점
- 아는 속성 조합: 줄거리 조각, 장면, 시기, 채널, 분량

**함정:** 속성 하나로 후보가 너무 많을 때 — 분포의 교집합으로 좁힌다.

---

## 7. 사람 — 누가 알고 있나?

- 커뮤니티, 포럼, Q&A, 이슈 트래커, 댓글, 후기, 분석 보고 (검색엔진의 사이트 한정 연산자 사용)
- 정보를 올린 사람의 이력(과거에 맞았는지)
- **사용자:** 기억이 흐릴 때는 질문을 1~2개로 줄이고, 열린 질문보다 **후보를 보여 주고 고르게** 한다.
  "방영 시기나 장면 하나만 기억나시나요?"

**함정:** 후기는 광고일 수 있고 소문은 틀릴 수 있다. 감정에서 출처 신뢰와 근거 수준을 표기한다.

---

## 8. 길 — 같은 시점에 다른 수단으로 갈 수 있나?

**공개적으로 허용된 대체 경로만:**
- 다른 검색엔진, 플랫폼 내부 검색, 사이트맵·RSS·피드, 공개 API와 공개 데이터셋
- 캐시·미러·아카이브(접근할 수 없을 때)
- 번역 도구로 언어 장벽 넘기, 지역 한정 사이트는 해당 지역 검색으로
- 도구 교체(웹 검색 ↔ 코드 검색 ↔ 파일 검색)

**하지 않는 것:** 로그인, 결제, 접근 제한, 차단을 **뚫는** 일. 허용되지 않은 경로는 쓰지 않고 "접근 불가"로 보고한다.
