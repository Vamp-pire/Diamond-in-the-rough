# 감정: 후보가 진짜인지 확인

"반짝인다고 다 금은 아니다." 후보를 모았으면 보고하기 전에 확인한다.
**가치나 취향 판단은 하지 않는다.** 진짜인지만 본다.

## 체크리스트

1. **실재** — 직접 열어서 존재하고 내용이 맞는지 본다. 검색 결과 요약만 믿지 않는다.
2. **관련성** — 요청한 것과 정말 맞는가? 이름만 비슷한 후보를 거른다.
3. **신뢰** — 출처가 믿을 만한가? 원 출처인가, 2차 인용인가?
4. **최신성** — 아직 살아 있나? 날짜, 버전, 링크 생존 여부.
5. **반대 증거 1회** — 이 후보가 틀렸다는 증거를 일부러 한 번 찾는다.

## 자주 걸리는 가짜 후보

- 이름만 비슷한 다른 대상
- 광고, SEO 스팸, 자동 생성 페이지
- 죽은 링크, 이미 닫은 서비스
- 옛 버전 정보
- 원문 없이 인용만 도는 2차 정보, 퍼온 글을 원본으로 착각한 것
- 검색 결과 요약과 실제 페이지 내용이 다른 경우
- 비슷한 도메인·이름으로 위장한 것(예: 철자가 한 글자 다른 주소, 하위 도메인으로 속인 주소)

## 이름만 비슷한 도메인 가려내기

대상이 도메인이면 아래로 판정한다. `scripts/normscan.py`가 '일치'와 '비슷한 이름'을 구분해 준다.

- **일치:** 호스트 전체가 같다. 왼쪽에 영숫자·하이픈이 붙지 않고, 오른쪽에 영숫자·하이픈이나 `.`+다른 라벨이 이어지지 않는다.
  `www.` 같은 하위 도메인은 같은 사이트로 본다.
- **가짜(제외):**
  - 접두·접미가 붙은 이름: `notX.io`, `X-archive.net`
  - 다른 TLD: `X.com`, `X.co`
  - 하위 도메인 위장: `X.io.evil.example` (실제 호스트는 오른쪽 끝)
  - 호모글리프: 키릴 `а` 같은 비ASCII 문자가 섞인 것(도구는 일부러 일치시키지 않으므로 의심되면 `isascii()`로 확인)
- 브랜드명이나 음역만 있는 문서는 **같은 서비스를 가리키는지 문맥으로 판단**하고, 도메인이 없으면 "부분"으로 표기한다.

## 강도

- **중:** 유력 후보 1~2개에 1~4번을 적용한다.
- **강:** 모든 후보에 1~5번을 적용한다.

## 두 가지 수준을 따로 표기한다

후보마다 아래 둘을 구분해서 적는다. 섞지 않는다.

**확인 수준 — 내가 얼마나 확인했나**
- **확인됨:** 직접 열어서 1~4를 확인
- **부분:** 일부만 확인 (이유를 적는다)
- **미확인:** 들은 것, 검색 요약만 본 것

**근거 수준 — 정보 자체의 출처가 얼마나 믿을 만한가**
- **공식 확인:** 공식 채널이나 운영 주체가 확인
- **독립 출처 일치:** 서로 독립된 출처가 같은 내용을 말함
- **단일 출처:** 하나의 출처뿐
- **소문:** 출처가 불분명하거나 검증할 수 없음

유출·비공식 정보는 근거 수준이 핵심이다. 정보를 올린 쪽의 과거 적중률, 근거 자료(파일·기록)와
주장의 일치 여부, 이후 공식 발표와의 대조 결과를 함께 적는다.
게시물은 작성 시점, 원글인지 퍼온 글인지, 수정 여부, 작성자 신뢰도도 확인한다.

## "없다"는 주장

확인 수준을 올릴 수 없다. 시도한 축과 기법을 보여 주고 "찾지 못함(미확정)"으로 보고한다.
단정은 고른 축 각각에서 기법을 시도한 뒤에만 한다.
