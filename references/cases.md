# 사례집

분류(8개 축)는 건드리지 않고 사례만 여기에 쌓는다. 새 사례가 기존 축으로 안 풀리면
`notes.md` 규칙대로 학습 노트에 기록한다. 사례를 일반화할 때는 축 이름만 쓰고 대상 이름은 쓰지 않는다.

| 사례 | 쓰는 축 | 기법 조합 | 메모 |
|---|---|---|---|
| 유입이 어디서 왔는지 모름 | 분포, 연결, 길 | 유입 기록 집계(`tally.py`) → 예상 밖 출처 → 출처 페이지 역추적 | 상위가 아니라 꼬리를 본다. 봇·내부 트래픽을 먼저 제거 |
| 내 사이트/특정 사이트가 등장한 글 | 표현, 위치, 연결 | 표기·인코딩 변형 + href·메타 위치 + 단축 링크 끝까지 | 비슷한 도메인은 미끼. 음역 표기("파트너허브")도 |
| 잘 안 알려진 사이트·도구 찾기 | 사람, 길, 분포 | 커뮤니티·후기 + 대안 목록 + 다른 검색엔진 | 상위 결과는 뻔한 것. 후기는 광고일 수 있다 |
| 표기가 다른 문서 | 표현 | 음역, 인코딩, 엔티티, base64, 쪼갬·전각 | 영문 이름의 한글 표기, 이중 인코딩 |
| 삭제·이동된 기능 | 시간, 연결, 성질 | git 이력 + 이동 후 이름 추적 + 하는 일로 찾기 | 이름이 바뀌었을 수 있다. 같은 커밋의 삭제와 추가를 본다 |
| 출시된 게임의 공식 발표 전 업데이트 정보 | 시간, 분포, 사람, 표현 | 선행 흔적 + 버전 비교(`diffsets.py`) + 분석 보고 + 코드명 | 근거 수준 표기 필수. 유출된 비공개 자료의 위치 안내는 하지 않는다 |
| 게시물 찾기 | 사람, 길, 시간, 표현, 연결 | 기억 되묻기 + 내부 검색 + 삭제본 + 캡처 글자 + 원글 추적 | 원글과 퍼온 글 구분, 작성자 이름 변경 가능성 |
| 잘 알려지지 않은 기능 | 위치, 시간, 연결 | 도움말·설정·소스 + 체인지로그 + 커뮤니티 | 문서에 없고 설정이나 코드에만 있는 경우가 많다 |
| 출연진과 일부 내용은 아는데 제목을 모르는 프로그램 | 성질, 연결, 분포, 사람, 표현 | 아는 속성 나열 → 활동명→본명 한 단계 풀기(표현) → 출연진별 출연작 목록(연결) → `intersect.py`로 교집합·연도로 좁힘(분포) → 줄거리로 확인(성질) → "제목 찾아요" 글(사람) | 문서마다 식별자가 다르다(활동명 vs 본명). 줄거리 키워드는 동의어로 바뀌어 있을 수 있어 단독으로 믿지 않는다. 후보가 여럿이면 남은 속성으로 거르고 사용자에게 되묻기 |

## 레시피: 로그에서 모르던 유입 출처 찾기

1. `tally.py <로그> --field 2 --unwrap --extract url --collapse-digits --all --sort asc` 로 전체 꼬리를 본다
   (글 ID가 쿼리에 있으면 `--extract urlq`).
2. 알려진 검색·소셜·봇 호스트를 `--ignore`로 걷어낸다. 구체적으로 쓴다(`search.naver.com`, `l.facebook.com`).
   `naver.com`처럼 쓰면 `blog.naver.com`의 글까지 사라진다.
3. 스팸 패턴(`word-word-숫자.tld`, `news-portal-숫자`)을 `--ignore-regex`로 걷어낸다.
4. 남은 것 중 **경로가 있는 글 URL**(블로그·커뮤니티·포럼)을 후보로 삼는다.
5. 목적지를 열어 확인할 수 없는 후보(단축 링크 `t.co` 등)는 "미확인 후보"로 따로 적는다.
6. 가능하면 후보를 직접 열어 감정한다. 막히면 한계에 적는다.

## 레시피: 표기가 다를 수 있는 언급을 전부 찾기

1. 용어, 음역(한글 표기), 브랜드명, 사용자의 말투를 모은다(`variants.py`).
2. `normscan.py <폴더> --term 도메인 --term 음역 --term 브랜드명` 으로 전수 스캔한다. 상태는 '일치', '비슷한 이름',
   '용어 일치(문맥 확인 필요)'로 나온다.
3. `variants.py <도메인> --regex` 의 정규식을 `grep -P`나 코드에 써서 보조 확인한다.
4. 단축 링크·짧은 ID가 있으면 매핑 파일에서 최종 목적지를 확인하고, 출발 문서까지 되짚는다(연결).
5. '비슷한 이름'은 제외 목록에 이유와 함께 적는다(접두·접미·다른 TLD·하위 도메인 위장·호모글리프).

## 사례 추가 형식

`사례 | 쓰는 축 | 기법 조합 | 메모(함정, 효과 있던 기법)`
